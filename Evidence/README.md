## How to add a real artefact

1. Check that you have permission to share the material publicly.
2. Upload an appropriately redacted screenshot, PDF, markdown note or text file into an appropriate goal folder, or link to a dated commit in an existing repository.
3. Replace the evidence row's **Pending** status with **Verified** only when the artefact is accessible and the claim matches what it proves.
4. Add one or two sentences explaining the result rather than presenting only a screenshot.
5. Include the evidence ID in the A3 report (for example, **E2.3**), so the assessor can follow the connection.

## Privacy and intellectual property

Do not publicly upload private grades with identifying details, student IDs, classmates' information, course materials you are not permitted to redistribute, copyrighted training content, secrets or sensitive data. Where required, provide a brief self-authored summary or appropriately redacted completion screenshot instead. Ask your subject coordinator if evidence visibility or format is unclear.
